# Evidence policy
Use `python3 .claude/ai-sdlc/scripts/verify_runner.py ID --name NAME -- COMMAND ARG...` for every required executable check. It records argv, exit code, time, HEAD and a hash of tracked/untracked working files (excluding docs/ai-sdlc and symlinks). This is a conservative freshness fingerprint: generated files may invalidate checks. It is not cryptographic attestation, a trusted CI result, or proof that AC mapping is truthful. Agent may edit acceptance_criteria and set top-level status to passed only after inspecting real results. Never manually manufacture a required runner check. `sdlc.py gate` rejects stale runner checks and missing AC evidence. Do not store raw output, secrets or personal data in evidence. If a command modifies worktree during execution, the check fails and must be rerun on stable code.
